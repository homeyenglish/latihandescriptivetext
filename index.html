Rangkuman Descriptive Text

1. Social Function / Purpose

Teks deskriptif bertujuan untuk menggambarkan orang, tempat, benda, atau hewan tertentu secara spesifik (to describe a particular person, place, animal, or thing).

2. Generic Structure (Struktur Teks)

  • Identification: Memperkenalkan subjek yang akan dideskripsikan (biasanya di paragraf pertama).
  • Description: Menjelaskan ciri-ciri khusus, sifat, penampilan fisik, perilaku, atau keunikan dari subjek tersebut.

3. Language Features (Ciri Kebahasaan)

  • Specific participant: Objek yang spesifik (contoh: My lovely cat Molly, Borobudur Temple, bukan kucing atau candi secara umum).
  • Simple Present Tense: Menggunakan kata kerja bentuk pertama (V1 / is / am / are) karena menyatakan fakta.
  • Adjectives & Adjective Phrases: Kata sifat untuk mendeskripsikan (contoh: fluffy, magnificent, ancient, tall).
  • Action Verbs: Kata kerja yang menggambarkan aktivitas nyata (contoh: runs, shines, sleeps).

Integrasi Google Spreadsheet

Kirim data nilai otomatis ke spreadsheet via Google Apps Script

URL ini akan otomatis digunakan untuk mencatat setiap siswa yang selesai mengerjakan tes.

Kode Apps Script (Salin & Pasang di Spreadsheet): 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Buat header otomatis bila sheet masih kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Timestamp", 
        "Nama Siswa", 
        "Kelas", 
        "Nilai (0-100)", 
        "Jumlah Benar", 
        "Jumlah Salah", 
        "Durasi Waktu", 
        "Predikat",
        "Detail Jawaban"
      ]);
      sheet.getRange(1, 1, 1, 9).setFontWeight("bold").setBackground("#e0e7ff");
    }
    
    // Tambahkan baris data siswa
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString("id-ID"),
      data.studentName,
      data.studentClass,
      data.score,
      data.correctCount,
      data.wrongCount,
      data.duration,
      data.predicate,
      data.answersSummary
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({
      result: "success"
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      result: "error", 
      error: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

Cara Memasang:

  1. Buka Google Sheets baru di browser.
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Hapus kode bawaan, lalu paste kode di atas. Klik simpan (ikon disket).
  4. Klik tombol Deploy (Terapkan) → New Deployment (Penerapan Baru).
  5. Pilih tipe Web app. Atur Execute as: Me dan Who has access: Anyone (Siapa saja).
  6. Klik Deploy, lalu salin tautan Web app URL dan tempelkan pada kolom di atas.
